## Worked example (real 2026-08-07 numbers, placeholder wording)

*EIA WPSR — week ending Aug 7, 2026*
*A 17.4M build against a −2.4M norm is a 20M-barrel surprise*

• Crude built 17.4M bbl in a week that normally draws 2.4M — a ~20M swing vs seasonal.
• Cushing jumped 1.6M to 22.6M, so the build landed at the hub, not just on the coasts.
• Runs slipped to 96.2% and gasoline drew 1.0M — nothing on the product side offsets the crude glut.

> *Call:* Bearish — WTI lower next week
> *Wrong if:* WTI closes above $81.70 (+3.5%) by next Friday

_Couldn't see: consensus build estimate, SPR flows, import attribution_
